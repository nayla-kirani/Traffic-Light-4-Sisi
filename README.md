# Traffic-Light-4-Sisi
TUGAS SISTEM MIKROKONTROLER
Rangkaian menggunakan 4 jalur, masing-masing jalur memiliki 3 LED (Merah, Kuning, Hijau) untuk menandai lampu lalu lintas. Semua LED dihubungkan ke Arduino UNO melalui resistor 220 Ω untuk membatasi arus.
•	Jalur 1 (TIMUR) → LED Merah, Kuning, Hijau → pin 2, 3, 4 
•	Jalur 2 (SELATAN) → LED Merah, Kuning, Hijau → pin 5, 6, 7 
•	Jalur 3 (BARAT) → LED Merah, Kuning, Hijau → pin 8, 9, 10 
•	Jalur 4 (UTARA) → LED Merah, Kuning, Hijau → pin 11, 12, 13 
Semua katoda LED dihubungkan ke GND Arduino.
